### 🚀 Sobre o Projeto
A **Calculadora de BTUs** é um aplicativo mobile nativo desenvolvido para Android com o objetivo de auxiliar no dimensionamento de aparelhos de ar-condicionado. A aplicação realiza o cálculo inverso, convertendo valores de **BTUs para metros quadrados ($m^2$)** de forma dinâmica e em tempo real à medida que o usuário digita.

---

### ✨ Funcionalidades
* **Interface Reativa:** Construída totalmente em **Jetpack Compose**, atualizando a tela instantaneamente através de estados (`remember` e `mutableStateOf`).
* **Validação de Entrada:** Tratamento para garantir que apenas números válidos sejam processados, evitando erros na aplicação.
* **Formatação de Resultados:** Exibição precisa do resultado formatado com duas casas decimais.
* **Telemática Otimizada:** Teclado numérico dedicado (`KeyboardType.Number`) com ação de conclusão (`ImeAction.Done`) para melhor experiência do usuário.

---

### 💻 Tecnologias Utilizadas
* **Linguagem:** Kotlin
* **UI Toolkit:** Jetpack Compose (Material 3)
* **IDE:** Android Studio
